# AgentForge 开发路线图

状态：已完成初始骨架与离线任务闭环；完整阶段验收仍在推进。更新日期：2026-10-28。

本路线图基于 [项目架构](architecture.md)，以可验证的业务流程推进，不预设未经验证的工期或并发容量。

- [x] Python 项目配置、依赖锁定、模块目录与开发说明。
- [x] API 任务提交、查询、取消及事件游标查询。
- [x] 按租户、空间和用户范围过滤任务与结果。
- [x] Alembic 初始迁移、任务与事件的事务持久化。
- [x] 单次 / 持续运行 Worker、模拟模型和内置报告工具。
- [x] SQLite 离线测试：越权拒绝、取消、并发领取、过期租约、恢复与重试上限。
- [x] 本地开发 PostgreSQL Compose 配置、连接示例及操作说明；仅静态校验。

## 阶段一：协议与数据边界

- [ ] 定义租户、用户、空间、Agent、会话、任务、执行尝试及产物的数据模型。
- [ ] 定义 Skill 的版本、输入输出、权限要求和验收标准。
- [ ] 定义 API、事件流、错误响应、审批与取消协议。
- [x] 明确首版数据库迁移入口、数据库任务队列和短任务租约语义。
- [ ] 盘点前端和桌面端的数据接口及业务代理依赖。

验收：用一个测试任务贯穿协议示例；服务端能够明确拒绝伪造身份、越权资源引用和跨范围记忆访问。

## 阶段二：Python 后端最小闭环

- [x] 建立 API、Worker、共享领域模块和自动化验证骨架。
- [ ] 启动本地 PostgreSQL 开发容器，验证迁移及 API / Worker 任务流程。
- [x] 实现任务持久化、领取、状态转换及可续传事件流，并通过 SQLite 离线测试。
- [ ] 接入一个模型路由，并实现单 Agent 的模型与工具循环。
- [ ] 接入一个离线测试工具，验证参数、结果和用量记录。
- [ ] 完成任务取消、模型失败和 Worker 中断后的恢复验证。

验收：从测试客户端提交任务，观察进度并得到持久化结果；重启 Worker 后历史仍可读取，任务不会无记录地消失。

## 阶段三：Docker 工具执行

- [ ] 实现 Python Supervisor 与 Docker Computer 的生命周期。
- [ ] 打通脚本执行、文件读写及产物下载。
- [ ] 配置独立工作目录、网络访问策略和资源限额。
- [ ] 实现超时、取消、回收和重新连接。
- [ ] 验证两个权限域的沙箱不能通过目录、产物接口或控制通道互访。

验收：一个 Agent 在授权沙箱中生成文件并返回结果；退出或重建沙箱后，约定持久化的文件仍可恢复。非幂等动作的结果不确定时，不直接重复执行。

## 阶段四：记忆与企业系统接入

- [ ] 实现会话摘要、Agent 记忆、用户记忆和显式共享记忆。
- [ ] 完成修订、删除、索引同步和权限过滤验证。
- [ ] 接入产品管理系统的知识和检索能力。
- [ ] 接入智能体广场与 Skill 广场的版本化资产。
- [ ] 对接企业模型路由和一个真实业务 API。

验收：使用真实但不敏感的业务样本完成任务；记忆和知识检索能返回来源，并能证明跨用户、跨空间、跨租户的访问受到对应约束。

## 首个业务验收场景

用户提交一份非敏感文档，指定 Agent 读取资料、调用一个工具并生成摘要或报告。系统需要展示执行进度，保存结果与产物，并验证其他无权限用户不能读取该任务、文件和记忆。
